# Wordle Unlimited Web App

This is a Python Flask web application that replicates the Wordle Unlimited game. You can run this locally, make guesses, and enjoy a game interface similar to the original Wordle.

## Features

- 6 guesses per game.
- Color feedback for each guess (green, yellow, gray).
- Simple grid interface styled similarly to the original Wordle.

## Installation and Running Instructions

### 1. Clone the repository or download the zip

Download the project files and navigate to the directory where they are located.

### 2. Set up the Python virtual environment

Make sure you have **Python 3.x** installed. Then, follow these steps:

# Navigate to the project directory
cd wordle-main

# Set up the virtual environment and install dependencies
